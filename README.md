# 餐具包装风格研究与比较

经所有者确认公开发布的文字流程技能。

适合为刀叉勺、餐具套装和折叠彩盒研究原创视觉方向、比较方案、精修已选稿。输入可以是本单需求、已确认素材和版面；输出为有依据的方向建议、比较记录和需要验证的事项。

## 使用

将整个目录交给支持 SKILL.md 的助手，明确要求读取 SKILL.md，再提供本单允许使用的资料。按所用产品当前官方安装方式配置技能目录；不要覆盖已经安装的同名内部版。未验证所有产品版本的自动发现。

纯文本工作流不需要 Python 或模型。外部研究需要可访问来源的工具；出图、设计编辑和印前检查需要另行提供相应能力。无法看图时只能做文字研究。
